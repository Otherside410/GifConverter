# GifConverter

Petit outil avec interface graphique pour convertir une video en GIF.

## Prerequis

- Python 3
- ffmpeg installe (ex: `sudo dnf install ffmpeg`)

## Lancer

```bash
python3 /home/otherside/Documents/GifConverter/main.py
```

## Notes

- Le champ largeur/hauteur a `0` conserve la dimension auto.
- Le filtre utilise palettegen/paletteuse pour une meilleure qualite.
